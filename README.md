# Blätterwald

Ein ruhiger Natur-Look für die Claude-Desktop-App: warmes Leinen als Grundfarbe, belaubte Zweige mit Buchen-, Linden-, Birken-, Weiden- und Eichenblättern, die sanft im Wind schwanken, und einzelne Blätter, die langsam herabfallen. Die Mitte bleibt frei für den Text. Hell- und Dunkelmodus werden beide unterstützt. Die Statuszeile zeigt 🍃 Blätterwald.

Hinweis: Die Szene zeichnet die Desktop-App. Terminal und Editoren zeigen keine Looks.

## Installation

Am Prompt einer Claude-Code-Sitzung:

```
/plugin install blaetterwald --marketplace gv656jzfj6-crypto/blaetterwald
```

Danach `y`, um den Marketplace hinzuzufügen, und einen Bereich wählen.

Aus einer Shell:

```bash
claude plugin install blaetterwald --marketplace gv656jzfj6-crypto/blaetterwald
```

Das Repository ist privat: Zum Installieren muss GitHub auf dem Rechner eingerichtet sein.
