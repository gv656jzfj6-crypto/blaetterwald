# Blätterwald

Ein ruhiger Natur-Look für die Claude-Desktop-App: belaubte Zweige mit Buchen-, Linden-, Birken-, Weiden- und Eichenblättern, die sanft im Wind schwanken, und einzelne Blätter, die langsam herabfallen. Die Mitte bleibt frei für den Text. Der Look ist fest auf Dunkel gestellt: warmes Walnussbraun mit gedämpften Blättern. Die Statuszeile zeigt 🍃 Blätterwald.

Hinweis: Die Szene zeichnet die Desktop-App. Terminal und Editoren zeigen keine Looks.

## Installation

Am Prompt einer Claude-Code-Sitzung:

```
/plugin install blaetterwald --marketplace gv656jzfj6-crypto/blaetterwald
```

Danach `y`, um den Marketplace hinzuzufügen, und einen Bereich wählen.

Aus einer Shell:

```bash
claude plugin install blaetterwald --marketplace gv656jzfj6-crypto/blaetterwald
```
